# CVF-AE Route B active pipeline

This note defines the maintained execution and paper-artifact chain after the
2026-08-01 cleanup. Files outside these chains are not required to reproduce the
current Route B results or manuscript figures.

## Formal selected-seven comparison

1. `run_cvf_ae_selected7_main_comparison.m`
2. `run_uav_comparison_lite_v2_batch.m`
3. `getUAVAlgorithmConfig.m`
4. `optimizer_AE_uav.m`, `optimizer_PSO_uav.m`, `optimizer_GWO_uav.m`,
   `optimizer_HHO_uav.m`, `optimizer_ERIME_uav.m`, `optimizer_MSCSO_uav.m`,
   and `optimizer_CVF_AE_uav.m`
5. `analyze_cvf_ae_trajectory_sanity.m`
6. `make_cvf_ae_selected7_paper_artifacts.m`

The maintained comparison dispatcher accepts only AE, PSO, GWO, HHO, ERIME,
MSCSO, and CVF-AE. Its default result source is the unified formal rerun.

## Formal ablation

1. `run_cvf_ae_formal_ablation.m`
2. `run_cvf_ae_gate_diagnostics.m`
3. `optimizer_AE_uav.m` and `optimizer_CVF_AE_uav.m`
4. `make_cvf_ae_corrected_ablation_artifacts.m`
5. `make_cvf_ae_ablation_summary_figure.m`
6. `make_cvf_ae_ablation_representative_figure.m`

The representative-path stage generates only the current six-variant Scene 3
three-dimensional overlay. It no longer invokes historical main or extended
comparison paths.
