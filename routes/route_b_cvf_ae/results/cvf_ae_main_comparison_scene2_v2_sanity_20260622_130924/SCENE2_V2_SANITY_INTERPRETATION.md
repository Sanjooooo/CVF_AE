# Scene 2-v2 小规模轨迹合理性验证

日期：2026-06-22

## 目的

原 Scene 2 在轨迹图上暴露出一个问题：多种算法容易出现贴近地图边缘、越过障碍物顶部或高空绕行。这样的场景过于紧张，会削弱 Scene 2 作为中等难度测试场景的解释力，也会让数值指标和低空 UAV 任务语义发生偏离。

本次调整将 Scene 2 改为中等约束走廊：

- 建筑数量从 13 个降为 10 个；
- 第一排建筑从 5 个改为 4 个，并扩大间距；
- NFZ 从 3 个降为 2 个；
- 风场热点从 4 个降为 3 个；
- 高度范围设置为 `[8, 32]`，参考巡航高度为 `16`。

## 验证配置

- scene: `2`
- algorithms: `CVF-AE`, `AE`, `PSO`, `GWO`, `WOA`, `HHO`, `DBO`, `CPO`
- runs: `5`
- population size: `20`
- max iterations: `80`
- base seed: `20260625`

结果目录：

`routes/route_b_cvf_ae/results/cvf_ae_main_comparison_scene2_v2_sanity_20260622_130924`

## 轨迹观察

- `CVF-AE` 的最佳轨迹走中低空通道，平均高度接近参考巡航高度，没有高空绕行标记，也没有明显长期贴边。
- `CPO` 仍取得最低平均 fitness，但最佳轨迹和统计指标显示其主要依赖较高高度穿越障碍物区域，`MeanHighAltitudeFrac = 0.74`。
- `GWO` 和 `DBO` 虽然多数 run 可行，但更容易采用地图边界附近的绕行路径。
- 调整后的 Scene 2 不再把所有算法都压到同一种高空或贴边策略，能够区分低空通道搜索能力、高空越障倾向和边界绕行倾向。

## 判断

保留 Scene 2-v2 作为新的中等难度场景是合理的。

后续建议：

- 不继续为了让 `CVF-AE` 数值排名压过 `CPO` 而调参；
- 将轨迹合理性指标纳入正式结果解释；
- 使用 Scene 2-v2 重新跑正式主对比，替换旧 Scene 2 结果；
- 正式主对比之后同步更新论文表格、轨迹图和统计检验。
