# Route A: COVE-AE Historical Line

This folder stores materials from the earlier COVE-AE route.

Route A was useful for identifying which mechanisms were supported:

- constraint-state initialization was consistently useful;
- sparse repair/reuse had mixed but sometimes positive support;
- violation feedback was not supported as a stable core innovation.

## Contents

- `results/`
  - Historical smoke, diagnostic, medium-gate, and formal ablation result folders.
  - These results are retained for traceability and comparison with project decisions.

## Status

Route A is not the current paper direction. The current focused direction is `CVF-AE` under `routes/route_b_cvf_ae/`.
