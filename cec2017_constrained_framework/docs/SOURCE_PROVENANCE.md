## Technical report

Guohua Wu, R. Mallipeddi, and P. N. Suganthan, "Problem Definitions and
Evaluation Criteria for the CEC 2017 Competition and Special Session on
Constrained Single Objective Real-Parameter Optimization", 2017.

The report defines the 28 functions, 10D/100D tracks, equality tolerance,
evaluation budget, 20-run protocol, feasibility rules, and result ranking.
