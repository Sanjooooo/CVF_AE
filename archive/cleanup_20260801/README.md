## Restore procedure

To restore an item, move it from its category directory back to the project root
using the relative path shown above. Check that the destination does not already
exist before restoring. Restore only the required item rather than merging the
entire archive into the active workspace.

Binary files in this archive may remain ignored by the repository's current Git
rules. Treat this directory as a local recovery archive unless those rules are
changed intentionally before publishing it.
